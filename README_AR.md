## 📱 مقدمة المشروع

### اسم المشروع
**أذكاري** - منصة إسلامية متكاملة

### الوصف المختصر
تطبيق ويب إسلامي شامل يجمع بين الأذكار، القرآن الكريم، مواقيت الصلاة، الإذاعة الإسلامية، والورد اليومي المتقدم. مصمم بعناية للمستخدم العربي المسلم لتسهيل الاستزادة من العلم الإسلامي والعبادة اليومية.

### الهدف من المشروع
توفير منصة موحدة تجمع أدوات إسلامية متعددة في واجهة حديثة وسهلة الاستخدام، تساعد المستخدم على:
- قراءة وحفظ القرآن الكريم مع التفسيرات
- الاستماع للتلاوات القرآنية والإذاعات الإسلامية
- المداومة على الأذكار بمختلف أنواعها
- متابعة مواقيت الصلاة في أي مكان بالعالم
- إعداد برنامج ورد يومي منظم مع تتبع التقدم

### الفئة المستهدفة
- المسلمون الباحثون عن منصة إسلامية شاملة
- الأشخاص الراغبون في تحفيز أنفسهم على قراءة القرآن بشكل منتظم
- المهتمون بالأذكار اليومية والعبادات
- الطلاب الراغبون في دراسة القرآن والتفسير
- مرتادو الإذاعات الإسلامية

## ✨ المميزات الرئيسية

### 1️⃣ مميزات الأذكار
- 📝 **أذكار الصباح والمساء**: مجموعة شاملة من الأذكار المأثورة عن الرسول ﷺ
- 📊 **عداد ذكي**: نظام عد الأذكار مع حفظ التقدم في كل جلسة
- 💾 **حفظ التقدم**: تخزين عدد الأذكار المكتملة محليًا على الجهاز
- 🎯 **تنظيم منطقي**: تصنيف الأذكار حسب النوع والفائدة الروحية
- ✨ **تصميم واجهة حديث**: شريط تنقل بنمط Glassmorphism مع تفاعلات سلسة وداعمة للهواتف والكمبيوتر
- 🔄 **نظام الورد المتراكم**: تجمع الصفحات التي فاتت في أيام غير مكتملة وتُضاف إلى الورد التالي عند انتهاء التعويض
- ♿ **تحسينات وصولية**: دعم التنقل بالكيبورد، حالات تركيز واضحة، ودعم تقليل الحركة عند الحاجة

### 2️⃣ مميزات القرآن الكريم
- 📖 **قراءة القرآن الكامل**: عرض كل السور والآيات بتنسيق احترافي
- 🔊 **التلاوات الصوتية**: استماع لتلاوات متعددة من قراء مختلفين
- 📑 **نظام الصفحات**: تصفح على شكل كتاب إلكتروني حقيقي
- 🔍 **البحث والملاحظات**: البحث عن آيات محددة مع الحفظ كـ pins
- 📚 **التفسير المدمج**: اطلاع على التفسير الميسر للآيات

### 3️⃣ نظام الورد اليومي (Wird)
- 📅 **إعداد برنامج يومي**: تحديد عدد صفحات القرآن المراد قراءتها يوميًا
- ⏱️ **تتبع التقدم**: عرض نسبة إكمال الورد مع شريط تقدم متقدم
- 🔄 **إدارة الأيام الفائتة**: نظام ذكي لمتابعة الأيام المفقودة والقضاء الموحد
- 🎉 **احتفالات البطولة**: رسوم متحركة عند إكمال قراءة القرآن كاملًا
- ⏰ **جدولة تلقائية**: تحديث تلقائي للورد كل فترة زمنية محددة
- 📌 **Pins الديناميكية**: الاحتفاظ بآخر آية تم وضع علامة عليها

### 4️⃣ مواقيت الصلاة
- 🕌 **تحديد الموقع**: اختيار الدولة والمدينة والحصول على أوقات الصلاة الدقيقة
- ⏳ **العد العكسي**: عرض الوقت المتبقي للصلاة التالية بدقة
- 📍 **تذكر المواقع**: حفظ آخر دولة ومدينة تم اختيارها
- 🌙 **معلومات التاريخ**: عرض التاريخ الهجري والميلادي الحالي
- 📊 **جدول الصلوات اليومي**: عرض أوقات جميع الصلوات المفروضة

### 5️⃣ الإذاعة الإسلامية
- 📻 **بث مباشر متعدد**: الاستماع لإذاعات إسلامية مختلفة
- 🔍 **بحث عن الإذاعات**: البحث عن إذاعة معينة حسب الاسم
- 🎵 **مشغل صوتي متقدم**: تحكم كامل بالتشغيل والإيقاف
- 📊 **عرض الإذاعات**: عرض قائمة الإذاعات بتنسيق مميز

### 6️⃣ ميزات تقنية متقدمة
- 💾 **التخزين المحلي**: حفظ جميع البيانات محليًا في localStorage
- 🌐 **عمل بدون إنترنت**: معظم المحتوى متاح حتى بدون اتصال إنترنت
- 📱 **تصميم متجاوب**: يعمل بكفاءة على جميع أحجام الشاشات
- ⚡ **أداء سريع**: تحميل سريع والاستجابة الفورية للتفاعلات
- 🔐 **أمان عالي**: معايير أمان HTTPS وCSP مطبقة

## 🛠️ التقنيات المستخدمة

### الـ Frontend
| التقنية | الإصدار | الغرض |
|---------|---------|-------|
| **React** | 19.2.6 | مكتبة الواجهات الأمامية |
| **React Router** | 7.15.1 | نظام التوجيه والملاحة |
| **SCSS/Sass** | 1.99.0 | معالج أنماط متقدم |
| **Embla Carousel** | 8.6.0 | عنصر الشرائط الانزلاقية |
| **React Player** | 3.4.0 | مشغل الفيديو والصوت |
| **H5 Audio Player** | 3.10.2 | مشغل الصوت المتقدم |

### أدوات التطوير
| الأداة | الإصدار | الغرض |
|------|---------|-------|
| **Vite** | 8.0.12 | أداة البناء والتطوير السريعة |
| **ESLint** | 10.3.0 | فاحص جودة الأكواد |
| **Vitejs Plugin React** | 6.0.1 | إضافة Vite لـ React |

### State Management
- **React Hooks** (useState, useEffect, useContext, useCallback, useMemo)
- **Context API**: للبيانات العامة مثل مواقيت الصلاة
- **localStorage**: لحفظ البيانات المهمة محليًا

### الـ APIs المستخدمة
| الـ API | الغرض | النوع |
|--------|-------|--------|
| **Aladhan API** | مواقيت الصلاة | REST |
| **QuranHub API** | بيانات القرآن والسور | REST |
| **Quranenc** | التفسير الميسر | REST |
| **Islamic Network** | تلاوات قرآنية صوتية | REST |
| **أذكار API محلي** | بيانات الأذكار | JSON محلي |

### الأمان والحماية
- **HTTPS Enforcement**: فرض استخدام HTTPS فقط
- **Content Security Policy (CSP)**: حماية من هجمات XSS والـ Injection
- **CORS Configuration**: تكوين آمن للطلبات بين النطاقات
- **SSL Certificate Validation**: التحقق من شهادات SSL
- **CSRF Protection**: رؤوس حماية CSRF

### النشر والاستضافة
- **Vercel**: منصة النشر والاستضافة
- **Next.js Configuration**: تكوين الإعادة والرؤوس الأمنية

## 🚀 خطوات التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
# استنساخ المشروع من GitHub
git clone https://github.com/yourusername/azkar.git

# الدخول إلى مجلد المشروع
cd azkar
```

### 2. تثبيت التبعيات
```bash
# استخدام npm
npm install

# أو استخدام yarn
yarn install

# أو استخدام pnpm
pnpm install
```

### 3. تشغيل التطبيق في وضع التطوير
```bash
# باستخدام npm
npm run dev

# أو باستخدام yarn
yarn dev

# أو باستخدام pnpm
pnpm dev
```

### 4. فتح التطبيق في المتصفح
بعد تشغيل الأمر السابق، سيظهر رابط في الطرفية (عادة `http://localhost:5173`)
افتح هذا الرابط في متصفحك لرؤية التطبيق

### 5. بناء نسخة الإنتاج (الإطلاق)
```bash
# باستخدام npm
npm run build

# أو باستخدام yarn
yarn build

```

### 6. التحقق من الأخطاء والجودة
```bash
# تشغيل ESLint للتحقق من جودة الأكواد
npm run lint

# عرض نسخة الإنتاج محليًا
npm run preview
```

## 🔧 إعداد المتغيرات البيئية

المشروع الحالي لا يتطلب متغيرات بيئية (.env)، حيث أن جميع الـ APIs المستخدمة عامة ولا تحتاج مفاتيح API سرية.

### ملفات التكوين المهمة

#### `vite.config.js`
يحتوي على:
- تكوين خادم التطوير
- إعدادات الأمان (HTTPS, CSP, CORS)
- Proxy لـ APIs الخارجية

#### `vercel.json`
يحتوي على:
- قواعس إعادة التوجيه (Rewrites)
- رؤوس الأمان (Security Headers)
- تكوين النشر على Vercel

#### `eslint.config.js`
يحتوي على:
- قواعد فحص جودة الأكواد
- معايير الكود المطلوبة

### ملف `.env` (إذا أردت إضافة متغيرات مستقبلًا)
```bash
# مثال فقط - المشروع الحالي لا يحتاج إلى هذا

# الـ APIs
VITE_PRAYER_API=https://api.aladhan.com/v1
VITE_QURAN_API=https://api.quranpedia.net/v1

# الإعدادات العامة
VITE_APP_TITLE=أذكاري
VITE_TIMEOUT=8000
```

## 📖 شرح طريقة الاستخدام

### رحلة المستخدم في التطبيق

#### 1️⃣ الصفحة الرئيسية (الأذكار)
```
التطبيق يفتح مباشرة على صفحة الأذكار
├─ اختيار نوع الذكر (صباح/مساء)
├─ عرض قائمة الأذكار
├─ الضغط على كل ذكر لزيادة العداد
├─ حفظ التقدم تلقائيًا في localStorage
└─ إعادة تحميل الصفحة → البيانات محفوظة
```

#### 2️⃣ قراءة القرآن الكريم
```
القائمة الجانبية → "القرآن"
├─ عرض كتاب القرآن الإلكتروني
├─ التنقل بين الصفحات
├─ وضع Pin على أي آية (بالضغط على رمز الدبوس)
├─ عرض التفسير الميسر
├─ الاستماع للتلاوة الصوتية
└─ الحفظ يتم تلقائيًا في localStorage
```

#### 3️⃣ الورد اليومي (Wird)
```
القائمة الجانبية → "الورد اليومي"
├─ الضغط على الترس لفتح الإعدادات
├─ تحديد عدد الصفحات في اليوم
```

## 🌐 توثيق الـ APIs

### 1. API مواقيت الصلاة
```
العنوان: https://api.aladhan.com/v1/timingsByCity
الغرض: الحصول على أوقات الصلوات
طريقة الطلب: GET
```

**المعاملات (Parameters):**
```
city: اسم المدينة (مثل "Cairo")
country: كود الدولة (مثل "EG")
method: طريقة الحساب (افتراضي: 5)
```

**مثال على الطلب:**
```javascript
// استخدام دالة getData الآمنة
import getData from './api/getData';

const fetchPrayerTimes = async (city, country) => {
  try {
    const data = await getData(
      `https://api.aladhan.com/v1/timingsByCity?city=${city}&country=${country}`,
      { timeout: 8000 }
    );
    console.log('أوقات الصلوات:', data);
  } catch (error) {
    console.error('خطأ في جلب البيانات:', error.message);
  }
};
```

```json
}
```

- الصور محسّنة والمضغوطة
- Tree-shaking من Vite

### ممارسات الأمان

#### 1. HTTPS Enforcement
```javascript
// في vite.config.js
if (isAbsoluteUrl && !normalizedUrl.toLowerCase().startsWith('https://')) {
  throw new Error('⚠️ يجب استخدام HTTPS فقط');
}
```

#### 2. Content Security Policy (CSP)
```
Content-Security-Policy: default-src 'self'; 
script-src 'self' 'wasm-unsafe-eval'; 
connect-src 'self' https://api.*.com; 
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com
```

#### 3. CORS Configuration
```javascript
// تحديد مصادر آمنة فقط
mode: 'cors',
credentials: 'omit',
cache: 'no-store'
```

#### 4. SSL/TLS Certificate Validation
- التحقق من شهادات SSL عند الاتصال
- رفض الاتصالات غير الآمنة
- منع MITM attacks

#### 5. CSRF Protection
```javascript
headers: {
  'X-Requested-With': 'XMLHttpRequest',
  'X-Custom-Auth': 'azkar-app-v1'
}
```

#### 6. Input Validation
- التحقق من صحة جميع المدخلات
- تنظيف البيانات قبل استخدامها
- منع حقن الأكواس الضارة
